# Hospital Database Management
Sistema de gestão de dados hospitalares para aprofundar conhecimento em **modelagem de dados, administração no PostgreSQL, performance, segurança e recuperação de dados**.
O projeto simula o ambiente de um hospital: gerenciamento de pacientes, profissionais de saúde, atendimentos, internações, exames e registros clínicos.

**Objetivo:** construir e administrar um bd hospitalar, desenvolvendo desde a modelagem inicial e desenvolvimento da aplicação, até a identificação e resolução de problemas.

### Escopo
O sistema deverá contemplar:

- Cadastro e histórico de pacientes; 
- Profissionais de saúde e especialidades; 
- Atendimentos e internações; ok
- Solicitação e realização de exames; 
- Prescrições e medicamentos; 
- Registros clínicos; 
- Controle de acesso aos dados;
- Backup e recuperação;
- Monitoramento e análise de performance; 

### Tecnologias Estimadas
- PostgreSQL
- Python
- Bash
- Git/GitHub
- Power BI
